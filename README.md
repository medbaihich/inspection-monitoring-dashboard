# Inspection Monitoring Dashboard

A Django REST API and React frontend extracted from my Smart Tomato Disease Monitoring project.

## Technology Stack

- Python and Django REST Framework
- React and Vite
- PostgreSQL
- Django Channels and Redis
- JWT authentication

## Features

- Inspection records and review workflows
- Device and catalog management
- Dashboard statistics
- Notification and WebSocket components
- API validation and duplicate handling

## Status

This repository is being separated from the original Edge AI and IoT project.

Some workflows may still depend on external AI components or services. Independent operation and complete integration testing are not yet verified.
